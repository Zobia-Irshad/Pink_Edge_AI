STEP-BY-STEP (uploads everything in ONE commit + opens the PR)
---------------------------------------------------------------------
1. Go to:  https://github.com/Zobia-Irshad/Pink_Edge_AI
   Make sure the branch selector (top-left of the file list) says "main".

2. Click the "Add file" button (top-right of the file list) →
   choose "Upload files".

3. Drag these items from your unzipped folder into the upload area
   (you can drop them all together):
        - the  App  folder
        - inference.py
        - requirements.txt
        - docker-compose.yml
   GitHub keeps the folder structure, so App/governance/..., App/Tools/...,
   App/Tests/... all land in the right place. Uploading inference.py,
   requirements.txt and App/requirements.txt on top of the existing ones
   simply REPLACES them with the updated versions — that is intended.

   (About .gitignore: see the note at the bottom — easiest to edit by hand.)

4. Scroll down to "Commit changes".
   - Commit message:  Add clinical governance layer: DICOM fail-safes, privacy, async, FHIR
   - Select the option:
        "Create a new branch for this commit and start a pull request"
   - In the branch-name box, type exactly:
        claude/dicom-privacy-clinical-governance-l3ye8f

5. Click "Propose changes".  GitHub opens the new Pull Request page.
   Add a title/description if you like, then "Create pull request".

That's it — the branch and PR now exist on GitHub.

THE .gitignore CHANGE (tiny — do it by hand on the website)
---------------------------------------------------------------------
Dotfiles like .gitignore sometimes don't show up when dragging, so the
simplest way is to edit it directly:

  1. On the new branch, open  .gitignore .
  2. Click the pencil (Edit) icon.
  3. Find the line that says:   *.db
  4. Add these TWO new lines right under it:
        *.db-wal
        *.db-shm
  5. Commit (to the same branch:
        claude/dicom-privacy-clinical-governance-l3ye8f ).

(If .gitignore DID upload fine in step 3, you can skip this section.)
